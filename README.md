# NoteBook 📝

A modern Notes App built with Kotlin, Jetpack Compose, Room Database, and MVVM.

## ✨ Features

- Create and save notes
- View note details
- Edit existing notes
- Delete notes
- Local data storage using Room Database
- Clean and simple Jetpack Compose UI

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
- Android Studio
